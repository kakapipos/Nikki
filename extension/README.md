# Nikki New Tab extension

A Manifest V3 extension for Chromium browsers such as Microsoft Edge. It replaces the New Tab page with a configurable image and lets you choose a size from 10% to 100%.

## Install in Microsoft Edge

1. Download this repository as a ZIP from GitHub and extract it.
2. Open `edge://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked** and select the extracted `extension` folder.
5. Open a new tab. To change the image or percentage, open the extension's **Details → Extension options**.

## Notes

- The extension replaces the New Tab page only. It does not change your existing homepage or existing tabs.
- Browsers require a user gesture for fullscreen; use the **Enter fullscreen** button. Press **Escape** to leave fullscreen or hide the image.
- You can hide the image using the visible button, and customize the image URL and size in Settings.
- The default image is hosted externally and needs internet access.
